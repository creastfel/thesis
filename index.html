巻 Mission Briefing

Understanding the mission objectives and the problem we set out to solve.

🎯

The Problem

Piglet crushing by sows is one of the leading causes of pre-weaning piglet mortality in commercial pig farming. This results in significant economic losses and raises serious animal welfare concerns. Traditional monitoring methods are labor-intensive and often fail to provide timely warnings.

💡

The Objective

Develop a deep learning-based early warning system using YOLOv11 instance segmentation that can detect and classify multiple piglet postures (lying, standing, piglet), enabling proactive intervention before crushing events occur.

🌟

The Significance

By achieving 98.44% mAP50 detection accuracy, this system can provide monitoring and alerts, reducing piglet mortality rates.

道 Mission Log

The journey from research to a fully deployed AI system.

Phase 1

📋 Research & Planning

Conducted extensive literature review on piglet crushing events, computer vision techniques, and YOLO architectures. Formulated the research problem and defined objectives.

Phase 2

📸 Data Collection

Gathered a comprehensive dataset of piglet and sow images in various postures — lying, standing, and general positions within pig pen.

Phase 3

🏷️ Data Annotation

Annotated images using Roboflow with 3 classes (lying, piglet, standing) in YOLOv11 format. Created polygon masks for instance segmentation.

Phase 4

🔧 Pre-processing & Augmentation

Applied grayscale conversion (CRT phosphor), auto-contrast stretching, and generated 5× augmented versions per image using flips and brightness adjustments. Final dataset: 10,109 images.

Phase 5

🤖 Model Training

Trained YOLOv11n-seg for 142 epochs using the Ultralytics framework. Used batch size 16, 640×640 image size, with pretrained weights.

Phase 6

📊 Evaluation & Validation

Achieved outstanding results — 98.44% mAP50 for detection and 98.10% mAP50 for segmentation. Generated confusion matrices, PR curves, and F1 curves for thorough analysis.

Phase 7

✅ Thesis Accepted!

Successfully defended and passed the undergraduate thesis. The system demonstrated reliable real-time detection of multi-posture piglet crushing events.
